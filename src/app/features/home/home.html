Every topic answers six questions

  1. What is it?
  2. Why does it exist — what problem does it solve?
  3. How does it work?
  4. Where is it used in practice?
  5. What should you learn before it?
  6. What comes after it?

If a topic cannot answer all six, it is not finished. That constraint is why this reads like an engineering handbook rather than a collection of notes.
